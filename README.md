# Научная среда

Автоматический еженедельный дайджест: по пять новостей из психологии, химии и
биологии. Статический сайт публикуется через GitHub Pages, а новый выпуск готовит
OpenCode Agent с моделью `opencode/deepseek-v4.1-flash-free`.

## Первоначальная настройка

1. Создайте репозиторий на GitHub и отправьте в него ветку `main`.
2. В `Settings → Secrets and variables → Actions` добавьте секрет
   `OPENCODE_API_KEY`.
3. В `Settings → Pages → Build and deployment` выберите источник `GitHub Actions`.
4. Откройте `Actions → Update news and deploy Pages → Run workflow`, чтобы создать
   первый полноценный выпуск сразу, не дожидаясь понедельника.

OpenCode GitHub App устанавливать не требуется: workflow запускает OpenCode CLI
на GitHub runner и коммитит проверенный результат встроенным `GITHUB_TOKEN`.

Затем workflow запускается каждый понедельник в 09:15 по московскому времени.
Предыдущий полноценный выпуск сохраняется в `data/archive/`. Новый выпуск
проверяется скриптом `scripts/validate_news.py`, коммитится напрямую в основную
ветку и сразу публикуется без ручного подтверждения.

## Ручное обновление через issue

Создайте обычный issue или откройте существующий и оставьте отдельный комментарий:

```text
/news
```

Команда принимается только от владельца `lordsynergy` и не срабатывает в pull
request. После успешной публикации бот ответит в issue ссылкой на обновлённый сайт.

## Локальный просмотр

Из корня проекта:

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000>. Для проверки сгенерированного выпуска:

```bash
python3 scripts/validate_news.py
```

Начальный `data/news.json` содержит заглушки. Первый ручной или плановый запуск
OpenCode заменит их пятнадцатью настоящими материалами.
